Тут каждый узнает о каждой мелочи утилиты

lsdr

1.3 | 28.07.2026

Одна из главных утилит всех времен! ls на линуксе, а на DOS и Windows эта утилита называлась dir. Эта версия отличается от первоисходников простым коротким кодом. Так же тут есть цветной вывод. И с недавнего времени его можно отключить, если вы желаете пользоваться белым выводом, с помощью флага -no-color.

теперь разбор кода

Начнем с импортов. импотируются:
  • unistd.h: для системных вызовов, типо write.
  • dirent.h: для работы с папкой, а точнее с чтением данных из папки
  • sys/stat.h: для получения информации, является ли объект папкой или файлом. Это для жирного вывода папок
    • Далее идут объявления функций strlen, strcmp, prints, printi, потом объявляются переменные: параметры папки (с помощью dirent.h), бъявление цветов, счётчик и int-type значения флагов (nocolor, numerate, showall...).
    Потом начинается главная функция main(int argc, char* argv[]). В ней уже начинается for цикл до тех пор пока аргументы не закончатся. После успешного (или не совсем) парсинга аргументов код переходит к исполнению, начинается while ((entry = readdir(dir)) != NULL). В нем происходят все события проверки значений цветов и состояние аргументов. там же находится вывод.
