# NeoUtils - Coreutils на C

**Всем привет!** Это *Neoutils*. Coreutils, который я **начал** писать 29 Июня 2026, и **выпустил релиз** 14 Июля 2026. Он был сделан **для дистрибутива *Progwilinux***.

[link to EN](README.md)

[вебсайт](https://neoriakm.github.io/neoutils)

## Содержание пака утилит

Neoutils содержит **9 утилит**: add, clear, dog, echo, lsdr, mov, wait, whereami, yes, yesno.

Каждая имеет аналог в GNU Coreutils. lsdr = ls, dog = cat, whereami = pwd.

Могу похвастаться тем, что мои утилиты весят 15 КиБ

## Как скачать

Просто скачайте вашу версию на [сайте](https://neoriakm.github.io/neoutils), и распакйте файл `all.zip`.

## Требования

- glibc.
- OS: Linux


> Если у вас нет glibc, скачайте файл из папки static/. весит больше, но работает везде.

> **Возможно** другие ОС могут запустить static версию. Я ничего не гарантирую
