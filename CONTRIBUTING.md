# How to add new util?

## 1. Clone repo

clone neoutils's repository, and do your work in the clone.

And, please, can you make new branch for your changes?

## 2. Make new file in `src/`

Make file with this command:

```bash
touch src/newfile.c
```

## 3. Writing a code

Write to file's header something like this

```c
// ------------------- //
// [your util]: [info] //
// Author: [your name] //
// ------------------- //
```

After, **just write a code**

## 4. End

Write info about your util, add it to **table** with utils.

Next, you need to submit a **pull request** to the official repository and wait for accepting.

If you have any problems, please make Issue in repository

**Thank you very much for your interest in contributing to Neoutils. ♥**
